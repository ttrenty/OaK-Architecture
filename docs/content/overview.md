# Documentation Overview

This site combines two kinds of documentation:

- authored guides written for the project
- generated API reference pages produced from the package docstrings

## Start here

- [Implementation guide](implementation-guide.html)
- [Minimal agent tutorial](tutorial-minimal-agent.html)
- [API reference](oak_architecture.html)

## What each section is for

- `overview.html`
  A short map of the documentation site.
- `implementation-guide.html`
  Guidance on how to approach a concrete OaK implementation.
- `tutorial-minimal-agent.html`
  A walkthrough of the small runnable example shipped with the package.
- `oak_architecture.html`
  The generated API reference for the package.

## Recommended reading order

1. Read this overview.
2. Read the implementation guide.
3. Run the minimal agent tutorial.
4. Use the API reference while implementing concrete classes.
